## 進場條件

### A+ 區（主戰場／防守區）
- 極限回調區，通常結合 4H / Daily BB 中軌
- 前壓力轉支撐（R→S）結構
- 最高優先，部位可加大

### A 區（次優，需確認 30m 結構）
- 趨勢中的「起漲點」或「缺口回補區（FVG）」
- 需看 30m K 棒結構確認再進

### S1 進場訊號三要素
1. 價格回調至關鍵位
2. 30m K 棒收下影線（錘頭型態）
3. AO 動能轉強（翻正）

### 進場等級
- S1：A+ 和 A 都做
- S2：A+ / A 優先；**B 級**（純錘頭 + 關鍵支撐，無 SMC 確認）縮小倉位 0.02 手執行，非優先選項（詳見 ANALYSIS_SKILL.md「S2 進場品質分級」）

## 分析架構（每次分析必須涵蓋）

### 大格局（Context）
- 先看前三週趨勢表（W-3, W-2, W-1）
- 確認目前是「主升」、「主跌」還是「盤整」

### 波動率
- 評估目前漲跌幅是否在日均震幅合理範圍（ATR）

### 宏觀層（每週日必查，Macro v3.7 截圖）
- **Macro Score 0–6**（Real Rate ×2 + US10Y + DXY + VIX + Gold MA50）
  - ≥ 5 → STRONG BUY；3–4 → NEUTRAL；2 → 視策略而定（S1 正常執行，S2-RSI/S2-Hammer 縮倉，20260621 修正，Score=2 不再等同 WAIT）；0–1 → WAIT 深度
- **GVZ**：< 13 Squeeze（S1 優先）；13–20 Normal；> 20 Extreme（**S1 不縮倉**，PF 仍佳；**S2 縮倉 50%**，20260621 修正）
- 截圖放 `googledrive/XAUUSD/weekly report/macro/`，合併週報時 AI 自動解讀

### 技術濾鏡
- BB（布林通道）：位置、寬度、%B
- AO（Awesome Oscillator）：方向、翻正/翻負
- 1H / 4H EMA 斜率
- DXY 趨勢：美元強弱對黃金的影響方向

### 位置濾鏡（關鍵）
- 支撐阻力（SNR）
- Fair Value Gap（FVG / 缺口）
- 溢價／折價區間（Premium / Discount）

### Session 濾鏡
- 亞/歐/美盤切換
- 星期行為分析（週幾的勝率特性）

## 每週工作流程

### 週日（週末周報）
1. 讀 Macro v3.7 截圖 → 確認 Macro Score + GVZ 狀態
2. 回顧前三週走向
3. 搭配布林通道 + S1-AweWithBB
4. 找出下週 A+ 與 A 的關鍵價位
5. 確認 DXY 趨勢方向
6. 輸出周報（劇本 A / B / C + 策略執行計畫）+ 依宏觀規則調整倉位

### 週三（週間更新）
1. 根據週日周報進行週四五調整
2. 預測週線如何收線
3. 確認是否有 A+ 機會
4. 若有重大波動，加開緊急週報

### 日常（TradingView 跳訊號時）
1. 手機收到 TV 通知
2. 開 Claude co-work → 請分析
3. 對比周報關鍵價位
4. 決定是否進場
