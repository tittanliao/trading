# 每月自檢清單 — 執行紀律與轉向訊號

> 來源：`reports/decision_review_20260710.md`（決策品質四合一報告）
> 用法：每月最後一個週末，對照 trade_journal 與 daily/ 紀錄逐項打勾。
> 打勾 = 警訊成立。填完把結果記在本檔底部的「檢查紀錄」。

---

## A. 失敗早期警訊（對應驗屍報告死因 1-3）

- [ ] 本月有任何一筆「到了 1R 但沒有落袋」或「訊號外進場」（死因1最早訊號，一筆就算）
- [ ] 本月 SOP 執行率 < 90%（journal 逐筆核對）
- [ ] 實盤滾動 20 筆的 R 期望值，比回測低 0.15R 以上
- [ ] out-of-sample 驗證還沒做（此格連續打勾越多個月，死因2機率越上調）
- [ ] 本月「系統/文件修改 commit 數」>「實盤交易筆數」×3（死因3量化訊號）
- [ ] 連續 2 週沒更新分析，或分析變成憑印象不走流程（死因3斷供前兆）
- [ ] 黃金月線跌破關鍵結構且 S1 訊號頻率/勝率明顯異常（死因2環境觸發）

## B. 轉向訊號（對應唱反調報告；中 2 條 = 黃燈，中 3 條 = 認真考慮「全自動 + 指數化」路線）

- [ ] 實盤累計 30 筆後，淨期望值 ≤ 0（以 R 計）
- [ ] S1 V3.7 的 out-of-sample 測試 PF < 1.2
- [ ] 近 3 個月 SOP 執行率 < 80%
- [ ] 系統文件行數持續成長，但月交易筆數沒有成長
- [ ] 連續兩個月，實盤績效落後「同期無腦持有黃金」
- [ ] 交易時薪 < 本業時薪的 1/4，且連續兩季

## C. 重大決定前檢查（不定期，做任何重大決定/進場前過一遍）

1. 這個決定違反我哪一條已寫下的規則？答案不是「沒有」→ 預設放棄。
2. 我現在想減倉/折衷/縮小規模嗎？是 → 那是「不要做」的訊號，改成二元：全規格做或不做。
3. 我是在訊號後 30 分鐘內、剛看完盤的狀態下決定的嗎？是 → 強制隔一根 K 棒（交易）或一晚（非交易）。
4. 執行端有機械保障（預掛單）嗎，還是靠到時候的意志力？
5. 這個新制度/新規則，誰來驗收它有沒有被執行？頻率？
6. 情緒分數幾分？4 分（有期待感）不是安全分數——期待感出現時倉位標準收緊。
